# UnityTranslateLib

A Kotlin and C++ library using [CTranslate2](https://github.com/OpenNMT/CTranslate2) to handle text translation natively using the [Argos Translate](https://github.com/argosopentech/argos-translate/) translation models, without the need of using Python.

This library is intended to be usable by Kotlin/JVM, but other bindings may be usable due to the C methods being exposed directly via the native module.
